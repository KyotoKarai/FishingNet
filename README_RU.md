## 📖 Обзор

Fishing Net — саморазворачиваемый сервис, который анализирует входящие письма и классифицирует их по уровню угрозы. Вместо сверки с базой известных сигнатур сервис оценивает смысл и контекст сообщения: манипулятивные техники, запрашиваемые действия, контекст отправителя.

Каждый вердикт возвращается с человекочитаемым объяснением причин.

## 🧠 Как это работает

Анализ идёт трёхступенчатым конвейером:

```
        входящее письмо
              │
   ┌──────────▼──────────┐
   │ Ступень 1 · техника │  SPF / DKIM / DMARC, репутация IP    (~0.1с)
   └──────────┬──────────┘
   ┌──────────▼──────────┐
   │ Ступень 2 · эвристика│ словарь соц. инженерии              (~1мс)
   └────────────────────┘
   ──────────▼──────────┐
   │ Ступень 3 · LLM     │  глубокий анализ контекста           (~3с)
   └──────────┬──────────┘
        ┌─────▼─────┐
        │  ВЕРДИКТ  │  + объяснение причин
        └───────────┘
```

> В текущем релизе реализованы ступени 2–3. Ступень 1 запланирована (см. Дорожную карту).

| Вердикт | Значение | Действие по умолчанию |
|---------|----------|----------------------|
| 🟢 Безопасное | обычная переписка | доставляется как обычно |
| 🟡 Подозрительное | найдены отдельные признаки | предупреждение пользователю + уведомление |
| 🔴 Фишинг | подтверждена соц. инженерия | карантин + алерт |

Письма, получившие красный вердикт на ступени 2, на ступень 3 не отправляются: очевидные случаи не требуют ресурсов LLM.

## 🔍 Пример детекта

> **Текст сообщения:**
> *«Срочно оплати счёт поставщика. Реквизиты в приложении. Конфиденциально, не обсуждай с коллегами. Жду подтверждение в течение часа.»*

Признаки, найденные анализатором:

- давление срочностью («в течение часа»)
- требование секретности («не обсуждай с коллегами»)
- имитация руководства («от директора»)
- запрос оплаты мимо обычных бизнес-процедур

Вердикт: 🔴 фишинг, с объяснением по каждому пункту.

## ✨ Возможности

- Трёхступенчатый конвейер анализа
- Объяснимые вердикты простым языком
- Двуязычный (RU/EN) словарь признаков соц. инженерии по категориям манипуляций
- Глубокий анализ через LLM с настраиваемым провайдером
- Уведомления через Telegram
- Саморазворачивание: Docker или чистый Python
- REST API для интеграции с внешними системами

## 🚀 Быстрый старт

### Локально
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # затем впишите свои ключи
uvicorn app.main:app --reload
```
Интерактивная документация API доступна по адресу http://127.0.0.1:8000/docs

### Docker
```powershell
docker-compose up --build
```

## ⚙️ Конфигурация

| Переменная | Назначение |
|------------|------------|
| `DEEPSEEK_API_KEY` | ключ LLM-провайдера (ступень 3) |
| `TELEGRAM_BOT_TOKEN` | токен бота для алертов |
| `TELEGRAM_CHAT_ID` | чат, куда приходят уведомления |

Без ключей сервис остаётся работоспособным: ступень 2 работает автономно, ступень 3 возвращает уведомление о деградации.

## 📡 API

`POST /analyze`
```json
{
  "subject": "Срочно оплатите счет",
  "sender": "ceo@fake-company.com",
  "body": "Не обсуждайте с коллегами. Переведите на новый счет поставщика в течение часа.",
  "headers": {}
}
```

Ответ:
```json
{
  "level": "red",
  "verdict": "Фишинг",
  "explanation": "...",
  "techniques": ["urgency", "secrecy", "money"],
  "confidence": 0.9,
  "advice": "..."
}
```
