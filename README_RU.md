## 🧨 Проблема

- **91%** успешных взломов начинаются с фишингового письма
- Корпоративные шлюзы (Proofpoint, Kaspersky) стоят **от $10 000/год** — малому бизнесу не по карману
- Встроенные фильтры ловят только **известные сигнатуры**; свежий фишинг проходит мимо
- Классический антиспам не понимает контекст: *«Оплатите счёт до 18:00, иначе штраф»* для машины выглядит легитимно

**Итог:** малый бизнес (1–100 сотрудников) практически беззащитен.

## 🧠 Решение

Трёхступенчатый конвейер анализа:

```
        входящее письмо
              │
   ┌──────────▼──────────┐
   │ Ступень 1 · техника │  SPF / DKIM / DMARC, репутация IP    (~0.1с)
   └──────────┬──────────┘
   ┌──────────▼──────────┐
   │ Ступень 2 · эвристика│ словарь соц. инженерии              (~1мс)
   └────────────────────┘
   ──────────▼──────────┐
   │ Ступень 3 · LLM     │  глубокий анализ контекста DeepSeek  (~3с)
   └──────────┬──────────┘
        ┌─────▼─────┐
        │  ВЕРДИКТ  │  + объяснение человеческим языком
        └───────────┘
```

> В MVP реализованы ступени 2–3. Слой SPF/DKIM/DMARC — следующий этап (см. Дорожную карту).

| Вердикт | Значение | Действие |
|---------|----------|----------|
| 🟢 Безопасное | обычная переписка | доставляется как обычно |
| 🟡 Подозрительное | что-то настораживает | пользователь предупреждён + уведомление SOC |
| 🔴 Фишинг | найдена соц. инженерия | карантин + алерт |

## ✨ Ключевая особенность: объяснимые вердикты

Каждое решение сопровождается объяснением простым языком.

> **Письмо от «директора» бухгалтеру:**
> *«Срочно оплати счёт поставщика. Реквизиты в приложении. Конфиденциально, не обсуждай с коллегами. Жду подтверждение в течение часа.»*

- **Сигнатурный АВ видит:** SPF валиден, ссылок нет, вложений нет → пропустить
- **Fishing Net видит:** давление срочностью + требование секретности + имитация руководства + оплата мимо процедур → 🔴 **фишинг**

## 🚀 Быстрый старт

### Локально
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # затем впишите свои ключи
uvicorn app.main:app --reload
```
Откройте http://127.0.0.1:8000/docs и попробуйте из интерактивной панели.

### Docker
```powershell
docker-compose up --build
```

## ⚙️ Конфигурация

| Переменная | Назначение |
|------------|------------|
| `DEEPSEEK_API_KEY` | ключ LLM DeepSeek (ступень 3) |
| `TELEGRAM_BOT_TOKEN` | токен бота для алертов |
| `TELEGRAM_CHAT_ID` | чат, куда приходят уведомления |
